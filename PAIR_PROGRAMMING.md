# Pair Programming

## Aplicação no projeto

Como o presente trabalho foi desenvolvido sem colaboração, a prática de pair programming não será aplicada diretamente durante a execução.

Caso o projeto fosse desenvolvido em dupla, a estratégia seria utilizar a programação em pares durante a implementação das novas funcionalidades do ESM Forum.

O trabalho seria dividido entre dois papéis:

- **Driver:** responsável por escrever o código e executar as alterações no projeto.
- **Navigator:** responsável por acompanhar o desenvolvimento, revisar o código, identificar possíveis erros e sugerir melhorias.

## Ferramentas

Para permitir o trabalho remoto em dupla, poderiam ser utilizadas as seguintes ferramentas:

- Visual Studio Code
- VS Code Live Share
- Discord ou Google Meet para comunicação por voz e compartilhamento de tela
- GitHub para controle de versão e acompanhamento das alterações

## Rotação de papéis

Os papéis de driver e navigator seriam alternados durante o desenvolvimento.

Uma possibilidade seria realizar a troca a cada funcionalidade ou após períodos de aproximadamente 30 minutos.

Dessa forma, os dois participantes teriam contato tanto com a implementação quanto com a revisão do código.

## Aplicação nas funcionalidades

O pair programming poderia ser utilizado principalmente durante:

- implementação da busca de perguntas;
- categorização das perguntas;
- sistema de votação;
- desenvolvimento do perfil de usuário;
- implementação das notificações.

Essa prática ajudaria na identificação de erros durante o desenvolvimento, na troca de conhecimento entre os participantes e na revisão contínua das decisões tomadas no código.
